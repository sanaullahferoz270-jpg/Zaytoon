      Security

      • Hiding this page is not security. Supabase Auth checks who you are, and the database's Row Level Security decides what you may change — on every single request.
      • Only accounts with the admin role can change restaurant data or images. Roles can only be changed by the project owner in the Supabase dashboard, never from this app.
      • Your sign-in is kept only while this page is open. Closing or reloading it signs you out.
      • No passwords, keys or admin secrets are stored in this app’s code or in the browser.
      • Only signed-in users with the admin role will be able to change data — enforced by the database.
